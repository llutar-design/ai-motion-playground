# 테스트 결과

- 실행일: 2026-11-09
- 환경: Windows 11, Chrome(헤드리스), Node 24
- 자동 테스트 합계: 단위 20/20, 브라우저 94/94 통과

## 검증 방식의 구분

| 표시 | 의미 |
| --- | --- |
| **모의** | 모의 관절 데이터로 MotionEngine과 게임을 실행. 인식 모델은 사용하지 않음 |
| **가상 카메라** | Chrome 가상 카메라에 실제 인물 사진을 넣고 실제 MediaPipe 모델로 추론. 정지 영상이라 움직임은 없음 |
| **미검증** | 사람이 실제 웹캠 앞에서 움직여야 확인 가능. 아직 수행하지 않음 |

**실제 사람이 웹캠 앞에서 움직이는 테스트는 아직 하지 않았습니다.** 12개 게임의 조작감, 도달 범위, 판정 난이도는 교실 시범 전에 직접 확인해야 합니다.

## 성능 측정값 (이 개발 PC, 헤드리스, 정지 영상)

게임 동작 중이 아니라 몸동작 테스트 화면에서 측정했습니다.

| 조건 | 추론 | 1회 처리 시간 | 화면 |
| --- | --- | --- | --- |
| 이 PC의 GPU | 15~20 FPS | 24~32ms | 135~152 FPS |
| 소프트웨어 렌더링 | 4~5 FPS | 202~265ms | 7~11 FPS |

다른 PC의 성능을 보장하는 값이 아닙니다. 사용할 기기의 **몸동작 테스트** 화면에서 실제 값을 확인해 주세요.

## 추가로 확인한 내용

- 프로덕션 빌드에서 외부 네트워크 요청 없음, CSP 적용, 콘솔 오류 없음
- 실제 사진의 팔 벌린 자세가 `arms_out`으로 판정되고 `both_up`과는 불일치
- 메뉴가 1920×1080, 1366×768, 1280×720에서 넘치지 않음
